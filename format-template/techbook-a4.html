1-1Webブラウザとサーバーの関係を理解しよう

Webプログラミングの世界へようこそ！ 私たちのスマートフォンやパソコンでWebサイトを見るとき、裏側では「クライアント（Webブラウザ）」と「サーバー」と呼ばれるコンピュータが常に会話（通信）を行っています。

この「リクエスト（要求）」と「レスポンス（応答）」のキャッチボールこそが、Webの基本となる仕組みです。

POINTここだけは覚える！ Web通信のキーワード

クライアント（Client）： サービスを利用する側。Google ChromeやSafariなどのWebブラウザのこと。
サーバー（Server）： サービスを提供する側。WebサイトのHTMLデータや画像、動画などを保管している専用コンピュータ。

1-2HTML / CSS / JavaScriptの役割分担

Webサイトの見た目を作る技術は、主に「HTML」「CSS」「JavaScript」の3つで成り立っています。建物を建てることに例えると、非常に直感的に理解できます。

言語 役割 建物に例えると…
HTML 骨組み・構造・文章 柱や床、壁などの基本構造そのもの
CSS 装飾・デザイン・配置 壁紙、塗装、インテリアなどの装飾
JavaScript 動き・対話機能 自動ドアやエレベーター、照明のスイッチ

コードを書いて動かすまでの3ステップ

STEP 1HTMLファイルを作成して基本構造を記述する
テキストエディタを開き、拡張子「.html」で保存します。
STEP 2CSSで文字の色やフォントサイズを指定する
デザインを指定して、見やすく美しいレイアウトに仕上げます。
HTML index.html (シンプルなWebページの例)
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>はじめてのWebページ</title>
</head>
<body>
  <h1>こんにちは、世界！</h1>
  <p>Webの学習をここからスタートしましょう。</p>
</body>
</html>
NOTEHTMLファイルはブラウザにドラッグ＆ドロップするだけで開ける！

作成した「.html」ファイルは、特別なサーバーを用意しなくても、お使いのブラウザアイコンの上にドラッグ＆ドロップするだけですぐに表示確認ができます。

WARNING全角スペースとファイル名の大文字・小文字に注意！

プログラミングで最も多い初心者のつまずきポイントは「全角スペース」の混入です。コード内の空白は必ず半角スペースを使いましょう。

COLUMN開発者ツール（F12）を使えば、どんなWebサイトの裏側も見られる？

閲覧しているWebサイトでキーボードの「F12」キーを押すと「デベロッパーツール」が開き、そのサイトがどんなHTMLとCSSで作られているかをリアルタイムで確認できます。

本格的にプログラミングを始めるために、世界中の開発者に最も支持されている無料の高機能エディタ「Visual Studio Code（VS Code）」を導入しましょう。
