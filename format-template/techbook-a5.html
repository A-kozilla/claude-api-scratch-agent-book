1-1Webブラウザとサーバーの関係を理解しよう

私たちがWebサイトを見るとき、裏側では「クライアント（Webブラウザ）」と「サーバー」と呼ばれるコンピュータが常に通信を行っています。

POINTここだけは覚える！ Web通信のキーワード

クライアント： サービスを利用する側（ブラウザ）。
サーバー： データを保管し、要求に応じて提供する側。

1-2HTML / CSS / JavaScriptの役割分担

Webの見た目を作る技術は、主に3つの言語で成り立っています。

言語 役割 建物に例えると
HTML 骨組み・文書構造 柱や壁・部屋の構造
CSS 装飾・レイアウト 壁紙・インテリア
JavaScript 動き・対話機能 自動ドア・照明スイッチ
HTML index.html
<!DOCTYPE html>
<html lang="ja">
<body>
  <h1>こんにちは！</h1>
</body>
</html>
NOTEHTMLはダブルクリックで開ける！

作成したHTMLファイルは、ブラウザにドラッグ＆ドロップするだけですぐに表示できます。

WARNING全角スペースに注意！

コード内に全角スペースが入るとエラーの原因になります。必ず半角を使用してください。

COLUMNF12キーで裏側が見える？

ブラウザで「F12」キーを押すと「デベロッパーツール」が起動し、どんなWebサイトでもHTMLやCSSの構造を覗き見ることができます。
