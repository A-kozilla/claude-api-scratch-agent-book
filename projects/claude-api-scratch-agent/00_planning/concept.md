# コンテンツコンセプトシート

## タイトル案
- メインタイトル: Claude APIでスクラッチから作るAIエージェント開発入門
- サブタイトル: SDKもフレームワークも使わず、HTTPリクエストだけでエージェントループからマルチエージェントまで自作できるようになる
- 検索キーワード: `Claude API`, `AIエージェント 自作`, `Tool Use`, `マルチエージェント`, `Python`

## 一言説明（30字以内）
HTTPだけでAIエージェントの仕組みを作って理解する講座

## 受講/読了/視聴後のゴール
- AIエージェントの基本構造（LLM＋ツール＋ループ＋コンテキスト）を、自分の書いたコードで説明できる
- Claude API（Messages API）をSDKを使わずHTTPで直接呼び出し、リクエスト／レスポンス／エラーを正しく扱える
- リトライ・ストリーミング（SSE）・コスト計測を備えた自作APIクライアントを実装できる
- ツール定義とエージェンティックループを自前で実装し、複数ツールを安全に扱うエージェントを作れる
- コンテキスト管理（トークン計測・要約・Prompt caching）とマルチエージェント構成（オーケストレーター＋サブエージェント、並列実行）を自分で設計・実装できる
- 本番運用を見据えた安全性・評価・コスト管理の勘所を押さえ、業務自動化エージェントを一人で作れる

## 強み・差別化ポイント
1. **ブラックボックスなしの完全スクラッチ**: SDKやエージェントフレームワークに頼らず、`httpx` で Messages API を直接叩くところから始める。フレームワークが裏でやっていること（履歴管理、ツールループ、リトライ、SSEパース、サブエージェント）を、すべて自分の手で実装して理解する
2. **1本のコードベースを育てる段階設計**: 第4章で作る自作クライアント `llm_client.py` を土台に、単一ツール → 複数ツール → コンテキスト管理 → マルチエージェント → 実践プロジェクトへと、同じコードを拡張しながら積み上げる。いきなり複雑な構成に挑んで挫折することを防ぐ
3. **仕組みが分かるから陳腐化しにくい**: HTTP・JSON・SSE・JSON Schema という標準技術の上に、API仕様（2026-10-21版）に準拠して組み立てる。特定ツールの使い方ではなく「エージェントがどう動くか」の原理が身につくため、他のフレームワークやモデルにも応用が利く
