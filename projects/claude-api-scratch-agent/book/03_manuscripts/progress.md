## 残課題（/verify-code・/factcheck-all で対応）
- 実行例の出力（トークン数・コスト・気温・ID等）は想定値。実API実行で差し替える（第2〜11章）。
- 他章の実装を推測して書いた箇所の照合: 第5・9章のログ／`tracker.summary()` 表示 → 第4章の確定形式に合わせる。第11章の report_agent 参照 → 第10章の確定名と照合。第12章の振り返り → 全章と照合。
- `max_tokens` 既定値: `call_messages` 16000 / `stream_messages` 64000（揃えるか判断）。
- 公式ドキュメントでの確認が必要な記述:
  - tool_result を text より前に置かないと400、ツール名の文字種・長さ（第5章）
  - Open-Meteo の利用条件（第5章）、Console のメニュー名・GitHub シークレットスキャンとの連携（第2章）
  - バッチ結果の `result.type`・`request_counts` のキー、effort と format の同時指定（第11章）
  - キャッシュ読み取り0.05倍（Opus/Sonnet 5.5）、最小キャッシュ長（第4・7章）
- 1文50字超の文が各章に一部残る（主に箇条書き・インラインコードを含む文）。
- 書籍の推定ページ数は /book-format 後に実測する。
