# 図11.6 スクリーンショット撮影手順

## 撮影する画面
Claude Console（`https://platform.claude.com/`）の **Usage** 画面。
日別のトークン数とコストの推移グラフが表示された状態を撮影する。

本文11.3節「コスト管理：予算を何重にも設ける」との対応:
- 利用状況（トークン数・コストの推移）＝ **Usage** 画面 ← 今回撮影する画面
- 利用上限（spend limit）＝組織は **Billing** 画面、ワークスペースは **Workspaces** の各ワークスペース設定（今回は撮影しない）
- 利用ティアとレート制限＝ **Limits** 画面（今回は撮影しない）

## 事前準備
- [ ] Claude Console にログインできるアカウント（Usage を閲覧できる権限）
- [ ] 数日分の利用実績があること（第10章のレポート作成や11.2節の eval を何日かに分けて実行しておくと、日別の推移が見えるグラフになる）
- [ ] 開発用と本番用でワークスペースを分けている場合は、撮影するワークスペース（例: 開発用）を決めておく
- [ ] ブラウザの拡張機能のアイコンやブックマークバーを非表示にする

## 撮影手順
1. ブラウザで Claude Console を開き、左メニューから Usage を選ぶ
2. 期間を「直近7日」〜「直近30日」程度にし、日別の棒（または折れ線）グラフが見える状態にする
3. 表示の切り替えがある場合は、トークン数とコストの両方がわかる表示にする（1画面で両方が出ない場合は、コスト表示を優先し、本文側で補足する）
4. グラフと期間・ワークスペースの選択欄が1画面に収まる状態でキャプチャする
5. macOS: Cmd+Shift+4 / Windows: Win+Shift+S

## サイズ・クロップ指示
- 推奨解像度: 1440×900以上（高DPIディスプレイ推奨）
- 書籍掲載サイズ: 横160mm（605px）に縮小
- クロップ範囲: Usage 画面の見出しからグラフ下端（凡例を含む）まで。左メニューは Usage の項目が見える幅だけ残す
- 隠すもの:
  - APIキー（キー名・キーの一部が表示されるフィルター欄や内訳表がある場合はぼかす）
  - メールアドレス（画面右上・左下のアカウント表示）
  - 組織名・ワークスペース名（実名の場合はぼかすか、撮影用の名前に変更してから撮影する）
  - 金額（実際の請求額・残高・合計コストの数値。グラフの形がわかればよいので、軸の数値と合計欄はぼかす）
  - URL バー内の組織ID等
