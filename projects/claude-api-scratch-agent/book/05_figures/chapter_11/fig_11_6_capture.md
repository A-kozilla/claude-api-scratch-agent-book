# 図11.6 スクリーンショット撮影手順

> 図11.6: Claude ConsoleのUsage画面とCost画面（第11章 11.3節「コスト管理：予算を何重にも設ける」）

## 撮影する画面
Claude Console（`https://platform.claude.com/`）の次の2画面を撮影し、左右（または上下）に並べて1枚の図にする。

1. **① Usage 画面**（`platform.claude.com/usage`）: 日別のトークン数の推移グラフが表示された状態
2. **② Cost 画面**（`platform.claude.com/cost`）: モデル別の支出（金額）の内訳が表示された状態

本文11.3節との対応:
- トークン数の推移＝ **Usage** 画面 ← 撮影する（①）
- 金額の推移・モデル別の支出＝ **Cost** 画面 ← 撮影する（②）
- 利用ティアとレート制限＝ **Rate limits** 画面（撮影しない）
- 利用上限（spend limit）の設定＝ **Billing** 画面（撮影しない）

## 事前準備
- [ ] Claude Console にログインできるアカウント（Usage と Cost を閲覧できる権限）
- [ ] 数日分の利用実績があること（第10章のレポート作成や11.2節の eval を何日かに分けて実行しておくと、日別の推移が見えるグラフになる）
- [ ] 複数のモデルを使った実績があること（第10章の CLI を実行すると、Opus・Sonnet・Haiku の3モデルが使われ、Cost 画面のモデル別の内訳が分かりやすくなる）
- [ ] 開発用と本番用でワークスペースを分けている場合は、撮影するワークスペース（例: 開発用）を決めておく
- [ ] ブラウザの拡張機能のアイコンやブックマークバーを非表示にし、ウィンドウを1440×900以上にする

## 撮影手順
1. ブラウザで Claude Console を開き、左メニューから **Usage** を選ぶ
2. 期間を「直近7日」〜「直近30日」程度にし、日別のトークン数のグラフが見える状態にする
3. グラフと、期間・ワークスペースの選択欄が1画面に収まる状態で①を撮影する
4. 左メニューから **Cost** を選び、①と同じ期間を指定する
5. モデル別の支出の内訳（グラフまたは表）が見える状態で②を撮影する
6. macOS: Cmd+Shift+4 / Windows: Win+Shift+S
7. 2枚を同じ高さにそろえて横に並べ、1枚の画像にまとめる（並べる余白は10px程度。各画像の上に「Usage」「Cost」と小さく見出しを入れてもよい）

## サイズ・クロップ指示
- 推奨解像度: 1440×900以上（高DPIディスプレイ推奨）
- 書籍掲載サイズ: 横160mm（605px）に縮小。2枚を横に並べると1枚あたり約300pxになるので、文字が潰れる場合は上下に並べる
- クロップ範囲:
  - ①: Usage 画面の見出しからグラフ下端（凡例を含む）まで
  - ②: Cost 画面の見出しからモデル別の内訳の下端まで
  - 左メニューは、どちらも画面名の項目が見える幅だけ残す
- 隠すもの:
  - APIキー（キー名・キーの一部が表示されるフィルター欄や内訳表がある場合はぼかす）
  - メールアドレス（画面右上・左下のアカウント表示）
  - 組織名・ワークスペース名（実名の場合はぼかすか、撮影用の名前に変更してから撮影する）
  - 金額（Cost 画面の合計額・軸の数値・内訳の金額。グラフの形とモデル名が分かればよいので、数値はぼかす）
  - URL バー内の組織ID等
