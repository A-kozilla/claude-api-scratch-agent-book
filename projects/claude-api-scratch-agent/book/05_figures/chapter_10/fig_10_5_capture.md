# 図10.5 スクリーンショット撮影手順

## 撮影する画面
レポート作成システムを1回実行した後の `workspace/runs/<実行ID>/` フォルダーを、ツリー表示で展開した状態。
本文10.1節・10.4節に合わせ、次のファイルとフォルダーがすべて見えていること。

- `plan.json`
- `notes/`（`q1.md`・`q2.md` … 問いごとの調査メモ）
- `drafts/`（`draft_v1.md`・`draft_v2.md`）
- `reviews/`（`review_v1.json`・`review_v2.json`）
- `report.md`
- `cost.json`

推奨は VS Code のエクスプローラー（サイドバー）です。`notes/`・`drafts/`・`reviews/` を展開し、`runs/` の上の `workspace/` と `sources/` も見える状態にすると、本文のディレクトリ構成図と対応が取れます。

- [ ] VS Code のテーマはライト系にする（印刷でのグレースケール化に強い）

## 撮影手順
1. VS Code でプロジェクトのルート `agent-from-scratch/` を開く
2. エクスプローラーで `workspace/` → `runs/` → `<実行ID>/` を展開し、さらに `notes/`・`drafts/`・`reviews/` を展開する
3. 本文の説明（10.4節「`review_v1.json` と `review_v2.json` を見比べる」）に合わせ、`reviews/review_v1.json` をエディター側に開いておくと、採点結果も同時に示せる（任意）
4. ファイルツリー全体が1画面に収まる状態でキャプチャする
5. macOS: Cmd+Shift+4 / Windows: Win+Shift+S

## サイズ・クロップ指示
- 推奨解像度: 1440×900以上（高DPIディスプレイ推奨）
- 書籍掲載サイズ: 横160mm（605px）に縮小
- クロップ範囲: エクスプローラーの `workspace/` から `cost.json` までのツリー部分（エディターを含める場合は `review_v1.json` の冒頭10行程度まで）
- 隠すもの:
  - APIキー（`.env` をエディターで開かない。ツリー上に `.env` が見える場合はファイル名だけなら可、内容は絶対に映さない）
  - ユーザー名・メールアドレスを含む絶対パス（ウィンドウタイトルやパンくずに `C:\Users\<名前>\` 等が出る場合はぼかす）
  - 組織名・社内資料名（`sources/` に社外秘の資料を置いている場合は、撮影用の資料に差し替える）
  - 金額: `cost.json` の内容を映す場合、本文の出力例と異なる金額になるため、ファイルの中身は映さない（ツリー上のファイル名のみ）か、ぼかす
