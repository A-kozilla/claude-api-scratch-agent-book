# 図2.3 スクリーンショット撮影手順

> 図2.3: 利用上限の設定画面（第2章 2.1節「利用上限（spend limit）を設定する」STEP 2）

## 撮影する画面
Claude Console（https://platform.claude.com）のワークスペース（Workspaces）画面で、学習用ワークスペース `agent-from-scratch` を選び、利用上限（Spend limits）の月額上限を入力している状態。入力値は本文に合わせて `10`（米ドル）にする。

## 事前準備
- [ ] Claude Console のアカウント（クレジット購入済み）
- [ ] 学習用ワークスペース `agent-from-scratch` を作成済み（既定の Default Workspace には上限を設定できないため、必ず作成したワークスペースを使う）
- [ ] ブラウザの拡張機能・ブックマークバーを非表示にし、ウィンドウを1440×900以上にする

## 撮影手順
1. Console にログインし、設定（Settings）→ ワークスペース（Workspaces）を開く
2. `agent-from-scratch` を選び、利用上限（Spend limits）の編集画面を開く
3. 月額上限の入力欄に `10` を入力した状態（保存前の入力済み状態）で撮影する
4. macOS: Cmd+Shift+4 / Windows: Win+Shift+S
5. 撮影後、実際に使いたい上限額で保存し直す

## サイズ・クロップ指示
- 推奨解像度: 1440×900以上（高DPIディスプレイ推奨）
- 書籍掲載サイズ: 横160mm（605px）に縮小
- クロップ範囲: ワークスペース名と Spend limits の入力欄・保存ボタンが入る範囲。左サイドバーはメニュー名が読める程度に一部のみ
- 隠すもの（必須）:
  - **APIキー**（画面内にキーの一部や末尾文字が表示される場合）
  - **メールアドレス**（画面右上のアカウント表示など）
  - **組織名**（組織切り替えメニュー・ヘッダー部分）
  - 実際の利用額・残高・請求情報・他のワークスペース名が映る場合はそれも隠す

- [ ] ワークスペース名 `agent-from-scratch` と上限額の入力欄が読めるか
- [ ] 拡大時に文字が読めるか
