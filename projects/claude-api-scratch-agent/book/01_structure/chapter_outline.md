# 書籍構成: Claude APIでスクラッチから作るAIエージェント開発入門 — HTTPリクエストだけでエージェントループからマルチエージェントまで

## 本書の構成方針
本書は、エージェントの仕組みをブラックボックスのまま使ってきた読者に、SDKもフレームワークも使わず、`httpx` で Claude API（Messages API）を直接呼ぶところから AIエージェントを組み立ててもらうための本です。読者は「エージェント＝LLM＋ツール＋ループ」の定義から出発し、自作APIクライアント、単一エージェント、コンテキスト管理、マルチエージェント、実践プロジェクト、本番運用へと、1つのコードベースを育てながら進みます。構成は はじめに → 基礎（第1〜4章）→ 応用（第5〜7章）→ 実践（第8〜11章）→ まとめ（第12章）の5部です。読み終えるころには、フレームワークが裏でやっていることを自分の言葉とコードで説明でき、業務用のエージェントを一人で設計・実装・運用できる状態を目指します。

## 設計上の意図
- **完全スクラッチ**: SDK・フレームワーク・Claude Code は使わず、`httpx` で Messages API を直接呼ぶ。API仕様・コード規約は `references/claude-api-facts.md` に統一する。
- **1つのコードベースを育てる**: 第4章の `llm_client.py` を全章で import し、第5章 `agent.py` → 第6章 `tool_registry.py` → 第7章 `context.py` → 第8章 `multi_agent.py` → 第9章 `patterns/` → 第10章 `report_agent/` と拡張する。
- **ステートレス性の3段階説明**: 1-3（概念）→ 3-4（履歴を自分で積み直す実装）→ 7-1〜7-2（トークン計測と圧縮）。
- **限界・安全性の分散配置**: 1-4（限界の先出し）、6-4（安全なファイル操作）、8-1・コラム（マルチエージェントのコスト）、9-1（エージェントを使わない判断）、第11章（本番運用）。
- Udemy講座との対応: 第1〜10章 ≒ Section 01〜10、第11・12章 ≒ Section 11。書籍は図解・原理・リファレンス性を厚くし、Udemyにない節（2-3 キー管理、11-4 バッチ、各コラム）を追加している。
