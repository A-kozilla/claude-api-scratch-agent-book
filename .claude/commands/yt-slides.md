# /yt-slides — YouTube動画用スライド生成

引数 `$ARGUMENTS`（例: `3`）で動画番号を指定。
台本（`yt-script`）と視覚素材指示書（`yt-visuals`）をもとに YouTube 用スライドデッキ（.pptx）を生成します。

---

## 前提確認

`youtube/03_scripts/video_{XX}.md` が存在しない場合: 「先に `/yt-script [N]` を実行してください」と伝えて終了。

---

## UdemyスライドとYouTubeスライドの違い

| 項目 | Udemy | YouTube |
|-----|------|---------|
| 主な用途 | 講義中の画面に映す | 動画内で見せる・切り替える |
| アスペクト比 | 16:9（1920×1080） | 16:9（1920×1080） |
| デザイン | クリーン・情報量多め | インパクト重視・テキスト少なめ |
| 文字量 | 箇条書き3点程度 | 1スライド1メッセージ（15字以内）|
| 視覚要素 | スライドが主役 | 動画・演出と組み合わさる脇役 |
| アニメーション | シンプル | ビルドアニメーションで1点ずつ表示 |

---

## スライドの種類と構成

台本のタイムスタンプ・演出メモをもとに以下の種類を判断して生成する。

| スライド種類 | 用途 | 枚数目安 |
|-----------|-----|---------|
| オープニングフック | 「この動画で得られること」を1行で提示 | 1枚 |
| セクションタイトル | パートの切り替えを示す | 2〜4枚 |
| キーメッセージ | 最も重要な概念を1文・大きな文字で | 2〜4枚 |
| 箇条書きまとめ | まとめパートで要点を1点ずつ表示 | 1枚（アニメーション） |
| コード表示 | ハンズオン動画でコードを画面に映す | 適宜 |
| エンドカードスライド | チャンネル登録・次の動画への誘導 | 1枚 |

**1スライドのテキスト量の上限**
- メインテキスト: **15字以内**（遠くから見ても読めるサイズ）
- サブテキスト: **20字以内 × 2行まで**
- コードスライドは例外（コード全体を読めるフォントサイズで）

## Step 1: `/mnt/skills/public/pptx/SKILL.md` を参照して生成

以下の仕様で `youtube/05_slides/video_{XX}.pptx` を生成・保存する。

### デザイン仕様（YouTube向け）

```
アスペクト比: 16:9（1920×1080px / widescreen）
背景: ダーク系グラデーション or 鮮やかな単色（動画との差別化）
メインフォント: 太字・60pt以上（Noto Sans JP Bold 推奨）
サブフォント: 28〜36pt
配色: 2〜3色に絞る（YouTube動画に重ねても視認性を確保）
アイコン: シンプルなフラットアイコン（装飾目的ではなく意味を持たせる）
アニメーション: まとめスライドのみビルドアニメーション（1点ずつフェードイン）
```

### スライドタイプ別デザインパターン

**① オープニングフック**
```
背景: ダーク（#1a1a2e または #16213e 系）
中央大見出し: [動画で得られること。15字以内]（白・72pt・太字）
下部小文字: [動画番号: タイトル]（グレー・24pt）
アクセント: 左端に縦線（アクセントカラー・8px幅）
```

**② セクションタイトル**
```
背景: アクセントカラー（明るい単色）
中央: [パートタイトル]（白・64pt・太字）
左下: アイコン（白・テーマに合うもの）
```

**③ キーメッセージ**
```
背景: ほぼ白（#f8f9fa）または薄いグレー
大見出し: [キーワード]（ダーク・80pt・極太）
サブ: [1文の補足]（ミディアムグレー・32pt）
アクセント: 見出し下に太い横線（アクセントカラー・6px）
```

**④ 箇条書きまとめ**
```
背景: ダーク系
タイトル: 「まとめ」または「今日のポイント」（白・48pt）
箇条書き: ✅ [要点]（白・36pt）× 3点
アニメーション: 1点ずつフェードイン（ビルドアニメーション）
```

**⑤ コード表示**
```
背景: #0d1117（GitHub Dark 風）
コード: 等幅フォント（Consolas / Source Code Pro）・22〜28pt
シンタックスハイライト: 言語に合わせて色分け
強調行: 背景色を変えてハイライト（#264f78 系）
ファイル名: スライド上部に小さく表示
```

**⑥ エンドカードスライド**
```
背景: チャンネルのブランドカラー
左: 「チャンネル登録はこちら 👆」（白・40pt）
右: 「次の動画 →」+ 次の動画タイトル（白・36pt）
下部: SNSアイコン・URLなど
```

## Step 2: スライドマップの生成

台本のタイムスタンプと各スライドの対応を `youtube/05_slides/video_{XX}_map.md` に保存する。

```markdown
# スライドマップ: 動画XX「[タイトル]」

| スライド番号 | 種類 | 内容 | 台本の対応箇所 | 表示タイミング |
|-----------|-----|------|-------------|------------|
| Slide 01 | オープニングフック | 「[一言]」 | オープニング 0:00 | 0:00〜0:30 |
| Slide 02 | セクションタイトル | 「[パート1名]」 | 本編パート1 | X:XX〜 |
| Slide 03 | キーメッセージ | 「[キーワード]」 | 本編パート1中盤 | X:XX〜 |
| Slide 04 | セクションタイトル | 「[パート2名]」 | 本編パート2 | X:XX〜 |
| Slide 05 | 箇条書きまとめ | 「まとめ3点」 | まとめパート | X:XX〜 |
| Slide 06 | エンドカード | チャンネル登録・次動画 | 最後5秒 | X:XX〜 |
```

---

## 保存先

- スライド: `youtube/05_slides/video_{XX}.pptx`
- スライドマップ: `youtube/05_slides/video_{XX}_map.md`

## 完了後の案内

以下を報告する:
- pptxファイルのパス
- 総スライド枚数
- スライドマップのパス

> **YouTubeでの活用方法**:
> - 解説パート: スライドを画面録画して動画に組み込む
> - ハンズオンパート: コードスライドを背景に映しながら実演
> - まとめパート: 箇条書きスライドをアニメーションで1点ずつ表示
> - エンドカードスライド: 動画末尾5秒に重ねる（YouTubeエンドカード設定と連携）
