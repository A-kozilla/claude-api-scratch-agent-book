# /review — 品質レビューサブエージェント

生成済みのすべてのコンテンツを専用サブエージェントが横断的にレビューします。
メインエージェントとは独立したコンテキストで動作するため、客観的な視点でチェックできます。

引数 `$ARGUMENTS`: `udemy` / `book` / `youtube` / `all`（省略時=all）

---

## 処理手順

### Step 1: レビュー対象の収集

対象メディアのファイルをすべて収集する。

### Step 2: メディア別レビューサブエージェントの起動

#### Udemyレビューサブエージェント

```bash
claude -p "
あなたはUdemy講座品質レビュアーです。以下のスクリプトファイルを横断的にレビューしてください。

## レビュー観点

### 個別チェック（各ファイル）
- [ ] 会話文字数が種類別目標を満たしているか（講義型: 1,600字以上 / ハンズオン型: 1,800字以上）
- [ ] 導入に「前回の振り返り」があるか
- [ ] 各トピックに「概念→具体例→重要性」の3段階説明があるか
- [ ] まとめに3点以上の箇条書き（各点に補足1文）があるか
- [ ] 次レクチャーへの橋渡しがあるか
- [ ] 書き言葉（〜である、〜における等）が混入していないか

### 全体チェック（シリーズ全体）
- [ ] 同じ説明が複数のレクチャーで重複していないか
- [ ] 難易度が段階的に上がっているか
- [ ] 各セクションの学習ゴールが達成されているか

## 対象ファイル
$(find udemy/03_scripts -name '*.md' ! -name 'progress.md' ! -name 'quality_report.md' | sort | while read f; do echo "=== $f ==="; cat "$f"; echo ""; done)

## 出力形式

### サマリー
- 総レクチャー数: X本
- 合格: X本 / 要修正: X本 / 重大問題: X本

### 問題一覧
| ファイル | 問題の種類 | 詳細 | 推奨対処 |
|--------|---------|------|--------|

### 全体所感
[シリーズとしての一貫性・品質の総評を200字以内で]
" > udemy/03_scripts/review_report.md

echo "✅ Udemyレビュー完了 → udemy/03_scripts/review_report.md"
```

#### 書籍レビューサブエージェント

```bash
claude -p "
あなたは技術書の編集者です。以下の原稿を横断的にレビューしてください。

## レビュー観点

### 個別チェック（各章）
- [ ] 「この章で学ぶこと」が冒頭にあるか
- [ ] 各節の導入に問題提起・疑問の言語化があるか
- [ ] 図マーカーが拡張フォーマットで記述されているか
- [ ] 「本章のまとめ」が末尾にあるか（3点以上）
- [ ] 次章への橋渡しがあるか
- [ ] 1文50字以内の読書体で書かれているか

### 全体チェック
- [ ] 前後の章で説明の重複・矛盾がないか
- [ ] 専門用語の初出説明が統一されているか
- [ ] 難易度の流れが「はじめに→基礎→応用→実践→まとめ」に沿っているか

## 対象ファイル
$(find book/03_manuscripts -name '*.md' ! -name 'progress.md' | sort | while read f; do echo "=== $f ==="; cat "$f"; echo ""; done)

## 出力形式

### サマリー
- 総章数: X章 / 合格: X章 / 要修正: X章

### 問題一覧
| ファイル | 問題 | 詳細 | 推奨対処 |
|--------|-----|------|--------|

### 編集総評
[書籍全体の品質・一貫性についての総評を200字以内で]
" > book/03_manuscripts/review_report.md

echo "✅ 書籍レビュー完了 → book/03_manuscripts/review_report.md"
```

#### YouTubeレビューサブエージェント

```bash
claude -p "
あなたはYouTube教育コンテンツのプロデューサーです。以下の台本を横断的にレビューしてください。

## レビュー観点

### 個別チェック（各動画）
- [ ] 1本の主題が1コンセプトに絞られているか
- [ ] 冒頭30秒にフック（問いかけ・数字・完成デモ）があるか
- [ ] 2〜3分ごとにパターン割り込みがあるか
- [ ] 会話文字数が種類別目標を満たしているか
- [ ] CTA（チャンネル登録・高評価）が1〜2回含まれているか
- [ ] エンドカード指示が末尾にあるか

### 全体チェック（シリーズ全体）
- [ ] ミニシリーズ単位でストーリーが完結しているか
- [ ] 動画間の橋渡し（「前回は〜」「次回は〜」）が自然か
- [ ] 検索流入を考慮した自己完結性があるか

## 対象ファイル
$(find youtube/03_scripts -name '*.md' ! -name 'progress.md' | sort | while read f; do echo "=== $f ==="; cat "$f"; echo ""; done)

## 出力形式

### サマリー
- 総動画数: X本 / 合格: X本 / 要修正: X本

### 問題一覧
| ファイル | 問題 | 詳細 | 推奨対処 |
|--------|-----|------|--------|

### チャンネル総評
[シリーズとしての視聴者体験・品質の総評を200字以内で]
" > youtube/03_scripts/review_report.md

echo "✅ YouTubeレビュー完了 → youtube/03_scripts/review_report.md"
```
