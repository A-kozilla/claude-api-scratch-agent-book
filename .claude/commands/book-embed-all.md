# /book-embed-all — 全章一括図埋め込み

全章の原稿に対して図の自動埋め込みを実行し、完全な最終原稿セットを生成します。

---

## 前提確認

`book/03_manuscripts/` と `book/05_figures/` が存在しない場合:
「先に `/book-all` と `/book-figures` を実行してください」と伝えて終了。

---

## 処理手順

1. `book/03_manuscripts/` 配下の全 `.md` ファイルを対象にリストアップする
2. `book/05_figures/` 配下の全図ファイルをスキャンして対応マップを作成する
3. 各章ごとに `/book-embed` と同じ手順で埋め込みを実行する
4. 進捗を都度表示する:
   ```
   [3/10] ✅ 第2章「タイトル」完了（図5点 / SVG:3点 PNG:2点 入稿待ち:0点）
   [4/10] ⚠️ 第3章「タイトル」完了（図4点 / SVG:2点 入稿待ち:2点）
   ```
5. 全章完了後に統合レポートを生成する

---

## 最終的なフォルダ構造

```
book/06_final/
├── chapter_00.md          ← はじめに（図埋め込み済み）
├── chapter_01.md          ← 第1章（図埋め込み済み）
├── chapter_02.md          ← 第2章（図埋め込み済み）
├── ...
├── figures_status.md      ← 全図の埋め込み状況レポート
└── README.md              ← 入稿時の注意事項
```

---

## 完了後の案内

```
✅ 全章の図埋め込み完了

処理章数: X章
埋め込み済み図: X点（SVG:X点 / PNG:X点）
入稿待ち: X点

最終原稿: book/06_final/
状況レポート: book/06_final/figures_status.md

入稿待ちの図がある場合は以下の手順で対処してください:
  1. figures_status.md で入稿待ち一覧を確認
  2. 対応ファイルを book/05_figures/ に配置
  3. /book-embed-all を再実行（済みの図はスキップ、新しいファイルのみ処理）
```
