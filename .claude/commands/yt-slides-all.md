# /yt-slides-all — YouTube 全動画スライド一括生成

引数 `$ARGUMENTS`: ミニシリーズ番号（省略時=全体）

---

## 前提確認

`youtube/03_scripts/` 配下にファイルが1つ以上存在しない場合: 「先に `/yt-script` または `/yt-all` を実行してください」と伝えて終了。

---

## 処理手順

1. 生成済み台本の総数をカウントして案内する:
   ```
   X本の台本からスライドを順次生成します。
   ```

2. 動画01から順に `/yt-slides` と同じ仕様で生成・保存する

3. 進捗を都度表示する:
   ```
   [3/20] ✅ 動画03「タイトル」完了（6枚）
   ```

4. 全完了後に `youtube/05_slides/slides_progress.md` を生成する:
   ```markdown
   # スライド生成進捗
   生成日: YYYY-MM-DD  完了: X/X本

   | # | タイトル | 枚数 | ファイル |
   |---|--------|-----|--------|
   ```

---

## 完了後の案内

```
✅ 全X本のスライド生成完了
総スライド枚数: X枚
保存先: youtube/05_slides/

台本・視覚素材指示書との対応は各 *_map.md を参照してください。
```
