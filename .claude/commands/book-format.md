# /book-format — 書籍原稿の飾り付き変換（Markdown / HTML+CSS / PDF / Word）

書籍原稿（Markdown）を、表紙・目次・章扉・囲み記事・コードブロック装飾つきの「飾り付き原稿」に変換します。
用紙サイズは **A4 / A5** から選べます。HTML/PDF のデザインは **`format-template/` のHTMLとCSS**（A4: `techbook-a4.html` + `style-a4.css` / A5: `techbook-a5.html` + `style-a5.css`）です。変換は Python スクリプト `.claude/tools/book-format/book_format.py` が行うため、同じ原稿からは毎回同じ結果になります。**AI（あなた）は原稿の文章を書き換えません。**

引数 `$ARGUMENTS`（順不同・すべて省略可）:

| 引数 | 値 | 省略時 |
|-----|---|-------|
| 出力形式 | `md` / `html` / `pdf` / `docx`（別名 `word`） / `all` | `all`（md・html・pdf・docx。python-docx が無ければ Word だけ飛ばす） |
| 用紙サイズ | `A4` / `A5` | `A5` |
| 章番号 | `3` / `1,3` / `0-2`（0=はじめに） | 全章 |
| 書名・著者・日付 | `title="..."` `subtitle="..."` `author="..."` `date="..."` | `book/book_info.md` → `concept.md` の順に取得。著者・日付はどちらにも無ければ空（表紙に出さない） |
| デザイン | `theme=classic` | `techbook`（format-template のデザイン）。`classic` は従来の簡素なデザイン（`.claude/tools/book-format/book.css`） |

例: `/book-format` / `/book-format pdf A4` / `/book-format docx A5`（Wordのみ） / `/book-format all A5 author="山田太郎"` / `/book-format html 2`

## デザインと原稿の記法

どの部品（表紙の各要素・章扉・節バッジ・囲み記事・ステップカード・会話ボックスなど）にするかは、**原稿の書き方（キーワード）で機械的に決まる**。
記法の全体は `references/book-markup.md` を Read ツールで読むこと。要点:

| 置き場所 | キーワード | デザイン上の部品 |
|--------|----------|--------------|
| `book/book_info.md` | `# TITLE:`（複数行可・`**強調**`）/ `# SUBTITLE:` / `# SERIES:` / `# DESCRIPTION:` / `# FEATURE:`（複数可）/ `# AUTHOR:` / `# PUBLISHER:` / `# DATE:` / `# HEADER:` | 表紙（書名・キャッチ・シリーズ名・説明・特長リスト・著者・出版社）、柱の書名 |
| 章ファイルの1行目の直後 | `# EN-TITLE: 英字` / `# TAGS: 語1, 語2` | 章扉の英字ラベル（CHAPTER 01 · …）・キーワードタグ |
| 章の先頭 | `## この章の概要` / `## この章で学ぶこと` / `> [!DIALOGUE]` | 章扉ページの概要枠・学習ゴール枠（✔付き）・会話ボックス |
| 本文 | `## 1.1 タイトル` / `### ` / `## COLUMN: タイトル` / `## 本章のまとめ` | 節見出し（番号バッジ）/ 小見出し / コラム枠 / まとめ枠 |
| 本文 | `> **POINT**: …` / `> **POINT: 見出し**` / `> **STEP 1**: 見出し` / `> [!DIALOGUE]` | 囲み記事（見出し付き可）/ ステップカード / 会話ボックス |

- デザインの元はテンプレートのCSSそのもの。**`format-template/style-a4.css`・`style-a5.css` を編集して再実行すれば出力に反映される**（出力先 `html/` にそのままコピーされる）。
- テンプレートにない部品（リスト・インラインコード・まとめ枠・TIP/DANGER など）と、Chrome で印刷するための補正は `.claude/tools/book-format/techbook-adapter.css`（テンプレートのCSSの後に読み込む）。
- テンプレートの柱の章名は `string-set`（paged.js 用）だが Chrome は未対応のため、章ごとの名前付きページで同じ表示にしている。テンプレートの paged.js 読み込み（`/api/docs_agent/...`）は使わない。

### `book/book_info.md` が無い場合

通常は `/book-structure` の実行時に `concept.md` から自動で作られる。無いのは、その変更より前に `/book-structure` を実行したプロジェクト。
変換前に、`book/book_info.md` が無ければ **`/book-structure` の「表紙情報 `book/book_info.md` の生成」と同じ手順で作ってから** 変換する（concept.md に書かれている内容だけを使い、著者名など不明な値は角かっこの未記入で残す）。作ったことは完了報告で知らせる。
concept.md も無い場合は作らずに変換する（表紙は書名だけになる。書名は `chapter_outline.md` またはプロジェクト名から取る）。

## 変換ルール（最重要・スクリプトが機械的に守る）

| ルール | 実装 |
|------|-----|
| 原稿の内容を勝手に削除しない | 変換後に**原稿の全行が出力に含まれているか自動チェック**する（HTML・Markdown・Wordのすべて）。欠けがあれば終了コード4で終了し、レポートに該当行を出す |
| 原稿にない事実を追加しない | 日付・著者は指定時（引数 / `book_info.md`）のみ表紙に出す。「第1章」は原稿の表記のまま表示する（`CHAPTER 01 · …` の英字ラベルは原稿に `# EN-TITLE:` があるときだけ）。図の「内容の要点」も入稿待ちの枠に残す |
| 意味を変えない | 文字は変更しない（構造の整理のみ）。整理した内容と件数はレポートに出す |
| 段落を整理する | 改行で折り返された段落を1段落にまとめる。style-guide の目安（6文）を超える段落は、文の切れ目（かっこ内・コード内の句点では切らない）で分割する |
| 見出し構造を整理する | 章の途中の `#` → `##`、レベルの飛び（`##`→`####`）の補正、`##見出し`（空白なし）の補完 |
| POINT / NOTE / WARNING / COLUMN | 引用ブロックの先頭ラベルで種別を決める（下表）。**ラベルのない引用は内容から推測せず、通常の引用のまま**表示する（推測で意味づけを足さないため） |
| デザインはテンプレートに従う | 配色・フォント・見出し・囲み記事・表・コード・表紙・目次・章扉は format-template のCSSどおり。テンプレートにない部品も同じ配色・部品の組み合わせで補う |
| A4 / A5 縦で印刷できる | テンプレートの `@page`（A4: 上20/右18/下22/左18mm、A5: 上15/右14/下16/左14mm）。ヘッダー・ページ番号は余白の帯の中に置き、本文と重ならない |
| ページ番号 | 表紙以外の全ページの下中央に「— N —」（テンプレートどおり）。表紙には付けない（番号のカウントは進む） |
| ヘッダー | 左上=書名（`# HEADER:` → 書名）、右上=章タイトル（章扉・本文とも）。表紙には出さない。目次ページは書名のみ |
| 目次 | 章・節（番号付きの節、コラム、まとめ）とページ番号「P. N」。ページ番号は1回目のPDFのしおりから読み取り、2回目の出力で書き込む（Chrome/Edge が必要。無ければ番号なし） |
| 章扉 | 章ごとに独立したページ（テンプレートの章トビラ）。「第N章」バッジ・章タイトル・タグ・概要・学習ゴール・会話を載せ、最初の節（`## X.1`）からは次のページ |
| ページ分割が不自然にならない | 見出しは直後の内容と離さない。**POINT / NOTE / WARNING / COLUMN・図・表・コードブロックは、可能な限り途中で分割しない**（行数の閾値は設けず、1ページに収まるものは必ず1ページに収める）。ページより長いコード・表だけがやむを得ず分割され、表は見出し行を繰り返す。「次のコード〜」のリード文は直後のコード・表・図と同じページにする |
| 日本語の禁則処理 | `line-break: strict`（行頭の「、。）」小書き文字を避ける）、`text-wrap: pretty`（最終行の1〜2文字残りを避ける）、見出しは文節で折り返し |
| コード・表・画像は読みやすさ優先 | コードは暗い背景の等幅・折り返し表示（切れない）、A4=8.5pt / A5=7.5pt。表は見出し行を強調。図は1ページに収まる大きさに縮小 |
| デザインより文章の読みやすさ | 本文は明朝体（テンプレートの本文サイズ・行間）。文字間が不自然に開く設定（本文への文節折り返し）は使わない |

### 囲み記事の判定（引用ブロックの先頭）

| 種別（techbook のデザイン） | 認識するラベル（大文字小文字・英日どちらも可） |
|-----|--------------------------------------|
| POINT（黄） | ポイント / 重要 / 要点 / POINT / IMPORTANT |
| TIP（緑） | ヒント / コツ / TIP / TIPS |
| NOTE（青） | 補足 / メモ / 参考 / 用語 / 具体例 / 例 / 注 / NOTE / INFO |
| WARNING（赤） | 注意 / 注意点 / よくある誤解 / WARNING / CAUTION |
| DANGER（濃い赤） | 警告 / 危険 / DANGER |
| COLUMN（点線） | コラム / 豆知識 / 余談 / COLUMN |
| STEP（ステップカード） | `**STEP 1**: 見出し` / `**ステップ1**: 見出し` |
| 会話ボックス | `[!DIALOGUE]` / `[!会話]` の後に `**名前**: 発言` |

書き方は `> **ポイント**: …` / `> **WARNING:** …` / `> 💡 **POINT**: …` / `> NOTE: …`（太字なしは完全一致のみ）/ `> [!TIP]` のいずれでも可。見出し付きは `> **POINT: 見出し**`（本文は次の行から）。ラベルの文字は原稿のまま表示する（`[!TIP]` 形式のみ、日本語ラベル「ヒント」に置き換える）。
`## コラム…` / `## COLUMN: …` / `## この章の概要` / `## この章で学ぶこと` / `## 本章のまとめ` の節は、見出しの文言で特別な枠にする。

## 前提確認

- `book/03_manuscripts/` に `chapter_XX.md` が存在しない場合: 「先に `/book-chapter` を実行してください」と伝えて終了。
- `projects/` 配下に書籍プロジェクトが複数ある場合は、どれを変換するかユーザーに確認する（1つだけなら自動で選ぶ）。
- 用紙サイズ・形式の指定が不正な場合は、指定可能な値を案内して終了。

## Step 1: 依存ライブラリの確認

```bash
python -c "import markdown, pygments, docx"
```

失敗した場合は次を実行してから続ける（`python` が無ければ `py -3` または `python3` を使う）:

```bash
python -m pip install markdown pygments python-docx pillow
```

PDF出力、およびWord出力でのSVG図の埋め込みには Chrome または Edge が必要（自動検出。PDFが作れない場合は Step 3 の案内を出す）。
`python-docx` が無い環境で `all` を指定すると Word だけ飛ばして警告する（`docx` を明示した場合はエラー）。

## Step 2: 変換の実行

```bash
python .claude/tools/book-format/book_format.py --project projects/{slug} --format {md|html|pdf|docx|all} --size {A4|A5} [--chapters 1,3] [--title "..."] [--subtitle "..."] [--author "..."] [--date "..."] [--theme classic]
```

`--template-dir` でデザインフォルダを差し替えられる（既定はリポジトリ直下の `format-template/`。`style-a4.css` / `style-a5.css` が必要）。

### 入力元の選び方（章ごとに自動判定）

| 状況 | 使うファイル |
|-----|-----------|
| `book/06_final/chapter_XX.md` がある | 図埋め込み済みの `06_final` を優先 |
| 無い | `book/03_manuscripts/chapter_XX.md`（図マーカーは変換時に処理し、`book/05_figures/` に図ファイルがあれば取り込む。無ければ「入稿待ち」の枠にする） |

`06_final` が `03_manuscripts` より古い場合はスクリプトが警告する → `/book-embed` の再実行を案内する。元原稿は一切変更しない。

### 終了コードの扱い（重要）

| 終了コード | 意味 | あなたの対応 |
|---------|-----|-----------|
| 0 | 内容チェックOK | 通常どおり完了報告 |
| 4 | **原稿の行が出力で見つからない** | 成功と報告しない。標準出力の該当行をそのまま示し、原因（原稿の書き方・変換ミス）を調べてユーザーに伝える。出力ファイルは採用前の確認が必要 |
| 1〜3 | 引数・依存ライブラリ等のエラー | メッセージに従って対処 |

### 用紙サイズごとの違い（techbook）

| | A4（210×297mm） | A5（148×210mm） |
|--|---------------|----------------|
| デザイン | `style-a4.css` | `style-a5.css` |
| 本文 | 9.75pt | 8.8pt |
| 余白（上/右/下/左） | 20/18/22/18mm | 15/14/16/14mm |
| コードの1行あたり目安 | 約94桁 | 約70桁 |

- HTML/PDF: テンプレートの `@page` で用紙サイズ・余白を設定（`--theme classic` では従来の見開き余白）
- Markdown: フロントマター（`papersize` / `geometry`）と `@page` を埋め込み（対応ツールでのPDF書き出し用）
- 目安の桁数を超えるコード行は警告が出る（PDFでは折り返して表示）

### 出力される装飾

| 要素 | HTML / PDF | Markdown |
|-----|-----------|---------|
| 表紙・目次 | テンプレートの表紙（グラデーション・シリーズ名・書名・特長・著者・出版社）+ ページ番号付きの目次（リンク付き） | YAMLフロントマター + 目次 |
| 章扉 | テンプレートの章トビラ（第N章バッジ・英字ラベル・タイトル・タグ・概要・学習ゴール・会話） | `# 第1章: …` をそのまま |
| 学ぶこと・まとめ・コラム | 学習ゴール枠 / まとめ枠（✔付き）/ 点線のコラム枠 | 引用ブロック |
| 囲み記事 | POINT/NOTE/WARNING/COLUMN のテンプレート枠（タグ + 見出し）、ステップカード、会話ボックス | `> **ラベル**: …` |
| コードブロック | 暗い背景・言語タグ・ファイル名・シンタックスハイライト | ファイル名（太字）+ コードブロック |
| 図 | 枠付き中央配置 + 「図X.Y:」キャプション（SVGはインライン、入稿待ちは点線枠） | 画像リンク + 斜体キャプション |
| ヘッダー・ページ番号 | 左上=書名、右上=章タイトル、下中央=「— N —」（PDF） | — |

## Step 3: 出力と保存先

```
book/07_publish/
├── A5/                        ← 全章変換（--chapters 指定時は A5_ch1-3/ のように別フォルダ）
│   ├── markdown/  book.md + images/
│   ├── html/      index.html + style-a5.css（テンプレートのコピー）+ book.css（補正・ページ設定）+ images/
│   ├── pdf/       book.pdf
│   ├── word/      book.docx                        ← 図・画像は文書内に埋め込み済み（単体で配布可）
│   └── publish_report.md     ← 内容チェック・整理した内容・図の状況・警告
└── A4/
```

- PDFの生成元としてHTMLを作るため、`pdf` のみ指定しても `html/` は残る（`md` のみなら `html/` は残さない）。
- Chrome / Edge が見つからずPDFが作れなかった場合は、`html/index.html` をブラウザで開き、印刷 → 「PDFに保存」（用紙サイズ=指定サイズ、余白=なし、背景のグラフィック=オン）を案内する。

## 完了後の案内

スクリプトの標準出力をもとに報告する:

```
✅ 書籍フォーマット変換完了（A5 / 全X章）
✅ 内容チェック: 原稿の全行が出力に含まれています

Markdown : book/07_publish/A5/markdown/book.md
HTML+CSS : book/07_publish/A5/html/index.html
PDF      : book/07_publish/A5/pdf/book.pdf（約Xページ）
Word     : book/07_publish/A5/word/book.docx

整理した内容（文字の追加・削除なし）: 段落結合X箇所 / 長い段落の分割X箇所 / 見出し補正X箇所
図: 埋め込み済みX点 / 入稿待ちX点
⚠ 警告: （あれば列挙）
```

- **「種別ラベルのない引用ブロック」が報告された場合**: POINT/NOTE/WARNING等にしたい引用があれば、原稿側の先頭を `> **ポイント**: …` の形に直すよう案内する（勝手に種別を推測して付けない）。
- 入稿待ちの図がある場合: 図ファイルを `book/05_figures/chapter_XX/` に配置して再実行するよう案内する。
- 見た目の調整（配色・フォント）は `format-template/style-a4.css`・`style-a5.css` の先頭 `:root` の変数を編集して再実行する（`--theme classic` のときは `.claude/tools/book-format/book.css`）。
- 表紙が書名だけの場合: `book/book_info.md`（記法は `references/book-markup.md`）を作ると、テンプレートどおりの表紙になることを案内する。

## Word（.docx）出力について

HTML/PDFと**同じルール**（分割抑止・内容チェック）で、Word文書を直接組み立てる（HTMLの変換ではない）。
Word版のデザインは従来（classic）のまま。format-template のデザイン（章トビラ・テンプレートの枠）は HTML/PDF のみに適用される（見出し付きの囲み記事・ステップ・会話は、ラベル付きの枠として出る）。

| 項目 | 内容 |
|-----|-----|
| ページ設定 | A4/A5縦。見開き用の左右対称余白（ノド側を広く）。奇数ページ=右、偶数ページ=左でヘッダー・ページ番号の位置が変わる |
| 構成 | 表紙 → 目次 → 章ごとに「章扉（タイトルだけの1ページ）」→ 本文。表紙・章扉はヘッダー/ページ番号なし |
| 見出し | Word標準の「見出し1〜4」スタイル（章タイトル=見出し1、節=見出し2）→ ナビゲーションウィンドウで移動できる |
| 囲み記事・コード・表 | 1つのセルの表として作る。1ページに収まるものは途中で分割しない（行が分かれない設定）。コードは色付き |
| 図 | SVGはChrome/Edgeで画像（PNG）にして埋め込む。PNG/JPGはそのまま。入稿待ちは点線の枠 |
| 禁則処理 | 有効。ただし「ぶら下げ」「行頭約物の詰め」「日本語と英数字の間の自動空白」は無効（余白を守り、HTML/PDFと見た目をそろえるため） |
| フォント | 本文=游明朝、見出し=游ゴシック、コード=Consolas系（Windows/Mac版Wordに標準搭載） |

**Wordで編集するときの注意**
- 目次は**静的なリンク付きの一覧**（ページ番号なし）。ページ番号つきの自動目次が必要なら、Wordで「参考資料 → 目次」を挿入する（見出しスタイルが付いているので、そのまま作れる）。
- 図（SVG）は画像として入るため、Word上で図形としては編集できない。
- Word 2013以降を想定（互換モード15）。

## 既知の制限

- **内容チェックは「原稿の各行の文字が出力に含まれるか」の検査**。順序の入れ替わりや、原稿にない文字が増えたことまでは検出しない（増える文字は、図の入稿待ち表示・目次・見出し番号・囲み記事の日本語ラベル置換 `[!TIP]`→「ヒント」など、決まった箇所のみ）。
- 目次のページ番号は、1回目のPDFのしおりと見出しの文字を照合して求める（PDFを2回生成するため時間が約2倍）。照合できなかった見出しは番号が空欄になる。`--theme classic` の目次にはページ番号は入らない。
- 章扉は左右どちらのページからでも始まる（奇数ページ始まりの白紙挿入はしない）。「この章で学ぶこと」が長いと章扉が2ページになる。
- テンプレートの `techbook-*.html` は構造の見本として参照するだけで、ファイルとしては使わない（paged.js の読み込み先がオフラインでは使えないため）。クラス名などの構造を変えた場合は `.claude/tools/book-format/techbook.py` も合わせて直す必要がある。
- 「1ページに収まるか」の境界ぎりぎりの表・コード（ページの高さとほぼ同じ）は、収まらないと判断されて分割されることがある。
- PDF上のヘッダー・ページ番号は用紙端から約8mm（A5）〜10mm（A4）の位置。プリンターの印字可能領域（一般に端から約5mm）に収まるが、それより狭い機種では欠けることがある。
- 段落の分割は文の切れ目（。！？）のみで判断する。英文が中心の段落や、句点のない長文は分割されない。
- 商業印刷の入稿用（塗り足し・トンボ・CMYK・フォント埋め込みの厳密な管理）ではなく、レビュー用・電子配布用・簡易印刷用のPDF。
- 表示フォントは環境依存（Noto Serif/Sans JP → 游明朝/游ゴシック → ヒラギノ → MS明朝 の順に使用）。
- Word版は Windows の Word 16.0 で開いて確認した。Mac版Word・LibreOffice・Google ドキュメントでの見た目は未確認（ヘッダーの左右切替や見開き余白は、アプリによって解釈が異なる可能性がある）。
- Word版で図（SVG）を画像にするには Chrome/Edge が必要。無い場合は該当の図が「入稿待ち」の枠になり、警告が出る。
