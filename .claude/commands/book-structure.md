---

## 前提確認
`00_planning/concept.md` が存在しない場合: 「先に `/plan [タイトル]` を実行してください」と伝えて終了。

---

## 参考情報の確認（必須）

`references/style-guide.md` はCLAUDE.md読み込み時点でセッションに適用済みのため、構成方針に反映する。特に`reference-doc.md`「技術参考情報」に関連URLがある場合、Claude API の各機能を扱う章の範囲・粒度が実際の機能と齟齬がないか、該当URLをWebFetchで確認してから構成する。

---

## 章立て設計ルール

- 総章数: 6〜20章（1章あたりA4原稿にして20〜40ページ目安）
- 各章に2〜10節
- 全体構成: **はじめに → 基礎 → 応用 → 実践 → まとめ** の5部構成を基本とする
- 各章の冒頭に「この章で学ぶこと」、末尾に「まとめ」を必ず入れる

## 表紙情報 `book/book_info.md` の生成

`/book-format` が表紙（format-template のデザイン）とヘッダーの書名に使う書誌情報を、`00_planning/concept.md` から作る。記法は `references/book-markup.md` の「1. 表紙・柱」に従う。

- **`book/book_info.md` が既にある場合は上書きしない**（ユーザーが編集済みの可能性があるため）。「既存の book_info.md を残しました」と案内するだけにする。
- **concept.md に書かれている内容だけを使う。** 書かれていない事実（著者名・出版社・シリーズ名・発行日など）は作らず、`[著者名]` のように角かっこの未記入のまま残す（未記入の値は表紙に出ない）。
- 文言は concept.md から写す。行分け・強調の位置は変えてよいが、言い換え・誇張・要約による新しい主張は足さない。

| キーワード | concept.md の取り出し元 | 書き方 |
|----------|---------------------|------|
| `# TITLE:` | 「メインタイトル」 | 表紙で読みやすい位置で1〜3行に分け、1行ずつ `# TITLE:` にする（文字は変えない）。書名の中心となる語句を1か所だけ `**…**` で囲む（強調色になる） |
| `# SUBTITLE:` | 「サブタイトル」 | そのまま |
| `# DESCRIPTION:` | 「一言説明」 | そのまま（長ければ区切りのよい位置で2行に分ける） |
| `# FEATURE:` | 「強み・差別化ポイント」の各項目の太字の見出し（強み1〜3） | 1項目1行。表紙の枠に収まるよう30字程度まで。説明文は写さない |
| `# HEADER:` | 「メインタイトル」 | 改行・強調なしの1行（ヘッダーの書名） |
| `# SERIES:` / `# AUTHOR:` / `# PUBLISHER:` / `# DATE:` | （concept.md に無い） | `[シリーズ名]` `[著者名]` `[出版社名]` `[発行日]` の未記入のまま |

出力例:

```markdown
# 書誌情報（/book-format の表紙・ヘッダーに使う）
<!-- concept.md から自動生成。[ ] の項目は未記入（表紙に出ません）。書き換えて /book-format を再実行してください -->

# SERIES: [シリーズ名]
# SUBTITLE: [concept.md のサブタイトル]
# TITLE: [メインタイトルの1行目]
# TITLE: **[メインタイトルの中心となる語句]**
# DESCRIPTION: [concept.md の一言説明]
# FEATURE: [強み1の見出し]
# FEATURE: [強み2の見出し]
# FEATURE: [強み3の見出し]
# AUTHOR: [著者名]
# PUBLISHER: [出版社名]
# DATE: [発行日]
# HEADER: [メインタイトル]
```

concept.md のメインタイトルが空欄・未確定（`[...]` のまま）の場合は `# TITLE:` も未記入で残し、完了報告で知らせる。
