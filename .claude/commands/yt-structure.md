## YouTube設計の基本原則

### 動画の長さ基準

| 目的 | 推奨時間 |
|-----|---------|
| フック（第1弾） | 3〜6分 |
| 解説・概念説明 | 5〜8分 |
| ハンズオン・実装 | 8〜12分 |
| まとめ・振り返り | 4〜7分 |
| Q&A・エラー解説 | 5〜10分 |

**20分を超える動画は原則作らない。** 長い内容は必ず複数本に分割する。

### 1本 = 1コンセプトの原則

```
❌「Dockerの基礎 — インストールから実行、ネットワーク、Composeまで」
✅「Dockerとは何か？3分でわかるコンテナの仕組み」      （動画01）
✅「Dockerインストール完全ガイド【Windows/Mac対応】」   （動画02）
✅「はじめてのdocker run — コンテナを起動してみよう」   （動画03）
```

### ミニシリーズ構造

大きなトピックを **ミニシリーズ（5〜8本）** に分割しプレイリストで束ねる。

```
シリーズ全体
├── ミニシリーズ1: 入門編（5〜8本）
│   ├── #01 フック動画（なぜ学ぶのか）
│   ├── #02 全体像の把握
│   ├── #03〜#06 基礎概念（1本1コンセプト）
│   └── #07 ミニシリーズまとめ＋次シリーズ予告
├── ミニシリーズ2: 基礎実践編（5〜8本）
└── ミニシリーズ3: 応用編（5〜8本）
```

## 生成内容

`youtube/01_structure/series_outline.md` を生成・保存する。

```markdown
# YouTubeシリーズ構成: [タイトル]

## シリーズコンセプト
**チャンネルの一言約束**: [視聴者への価値提供を1文で]
**総動画本数**: X本（ミニシリーズX個）
**投稿ペース**: 週X本（全X週で完結）
**SEOキーワード**: `キーワード1`, `キーワード2`

---

## ミニシリーズ1: [タイトル]（X本 / プレイリスト名: [名前]）

**このミニシリーズで得るもの**: [〜できるようになる]

| # | タイトル案 | 種類 | 推定時間 | 1本の主題（1コンセプト） |
|---|---------|------|---------|---------------------|
| 01 | | フック | X分 | |
| 02 | | 解説 | X分 | |

---
（以下ミニシリーズ2, 3...）

## 全体統計
| 総ミニシリーズ数 | 総動画本数 | 推定総視聴時間 | 平均動画長 |
|------------|---------|------------|---------|
| X | X本 | X時間X分 | X分 |

## 視聴者の導線設計
- 初見: 動画01 → ミニシリーズ1完走 → ミニシリーズ2
- 検索流入: 各動画 → 同ミニシリーズ先頭 → シリーズ全体
- 途中離脱: 各ミニシリーズの「まとめ動画」から再開
```
