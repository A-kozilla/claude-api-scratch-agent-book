# /factcheck-all — 全コンテンツ一括ファクトチェック

生成済みのすべてのコンテンツに対してファクトチェックとコード検証を実行します。
公開前の最終品質保証として使用してください。

---

## 処理手順

### Step 1: 対象ファイルの収集

生成済みのスクリプト・原稿・台本を全収集する。

### Step 2: サブエージェントによる並列ファクトチェック

メディアごとにファクトチェックサブエージェントを並列起動する:

```bash
# Udemy・書籍・YouTubeを並列でファクトチェック
for MEDIA in udemy book youtube; do
    claude -p "
/factcheck の手順に従い、${MEDIA} の全コンテンツをファクトチェックしてください。

対象ファイル:
$(case $MEDIA in
  udemy) find udemy/03_scripts -name '*.md' ! -name '*_factcheck.md' | sort ;;
  book) find book/03_manuscripts -name '*.md' ! -name '*_factcheck.md' | sort ;;
  youtube) find youtube/03_scripts -name '*.md' ! -name '*_factcheck.md' | sort ;;
esac)

各ファイルのファクトチェック結果を対応する _factcheck.md ファイルに保存してください。
" &
done
wait
```

### Step 3: コード検証

コードブロックを含むファイルに対してコード検証を実行する:

```bash
claude -p "
/verify-code の手順に従い、全コンテンツのコードブロックを検証してください。
エラーが発生したコードは修正案を提示し、対応する _code_verify.md に保存してください。
"
```

### Step 4: 統合レポートの生成

全メディアの結果をまとめた統合レポートを生成する:

```markdown
# ファクトチェック統合レポート

実行日: YYYY-MM-DD

---

## サマリー

| メディア | 検証クレーム | ✅ 正確 | ⚠️ 要確認 | ❌ 要修正 |
|--------|-----------|--------|---------|---------|
| Udemy  | X件 | X件 | X件 | X件 |
| 書籍   | X件 | X件 | X件 | X件 |
| YouTube| X件 | X件 | X件 | X件 |
| **合計** | **X件** | **X件** | **X件** | **X件** |

| コード検証 | 確認済み | ⚠️ 要確認 | ❌ エラー |
|---------|--------|---------|--------|
| 全メディア | X個 | X個 | X個 |

---

## 優先対処リスト（❌ 要修正）

公開前に必ず修正してください:

1. **[ファイル名]** — [問題の概要]
   → 修正案: [具体的な修正内容]

2. ...

---

## 推奨確認リスト（⚠️ 要確認）

公式ドキュメントで最新情報を確認してください:

1. **[ファイル名]** — [確認が必要な内容]

---

## 公開判定

- ❌ 要修正が0件: **公開可能**
- ❌ 要修正が1件以上: **要修正後に再チェック**
```

統合レポートの保存先: `projects/{slug}/factcheck_report.md`

---

## 完了後の案内

```
✅ 一括ファクトチェック完了

統合レポート: projects/{slug}/factcheck_report.md

❌ 要修正: X件 → 公開前に必ず対処してください
⚠️ 要確認: X件 → 公式ドキュメントで確認を推奨します

【公開前チェックリスト】
- [ ] ❌ 要修正をすべて修正した
- [ ] ⚠️ 要確認を公式ドキュメントで確認した
- [ ] コードエラーをすべて修正して動作確認した
- [ ] 実際の学習環境（受講者と同じ環境）でハンズオンを通しで実施した
```
