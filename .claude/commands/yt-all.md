# /yt-all — YouTube 全台本一括生成

引数 `$ARGUMENTS`: ミニシリーズ番号（省略時=全体）

---

## 前提確認
`youtube/02_list/video_list.md` が存在しない場合: 「先に `/yt-list` を実行してください」と伝えて終了。

---

## 処理手順

1. `video_list.md` を読み込み、対象動画数をカウントして案内する
2. 動画01から順に `/yt-script` と同じテンプレート・品質基準で執筆・保存する
3. 進捗を都度表示する:
   ```
   [3/20] ✅ 動画03「タイトル」完了（会話文1,050字 / 推定7分）
   ```
4. 全完了後に `youtube/03_scripts/progress.md` を生成する

---

## 完了後の案内

```
✅ 全X本の台本生成完了
総会話文字数: X字 / 推定総視聴時間: X時間X分 / 警告あり: X本

'/yt-visuals [番号]' で視覚素材指示書を生成できます。
'/export youtube' で全台本を1ファイルに結合できます。
```
