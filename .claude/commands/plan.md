# /plan — 共通企画フェーズ

引数 `$ARGUMENTS` をタイトル・トピックとして受け取り、全メディア共通の企画書を生成します。

---

## Step 1: 情報収集

以下が不明な場合のみ、まとめて一度確認する：

1. 制作するメディア（Udemy / 書籍 / YouTube / すべて）
2. ターゲット（例: Python初心者 / 非技術系ビジネスパーソン）
3. コンテンツの性質（コード・ハンズオンあり / 講義・解説中心）
4. ボリューム目標（Udemy: X時間 / 書籍: Xページ / YouTube: X本）

---

## Step 2: ディレクトリ作成

タイトルから project-slug を生成（英語 kebab-case）し、以下を作成する：
```
projects/{project-slug}/00_planning/
```

---
