# /yt-script — YouTube 動画台本執筆

引数 `$ARGUMENTS`（例: `3`）で動画番号を指定。

---

## 前提確認
`youtube/02_list/video_list.md` が存在しない場合: 「先に `/yt-list` を実行してください」と伝えて終了。
引数がない場合: 「動画番号を指定してください（例: `/yt-script 3`）」と伝えて終了。

---

## 会話文字数の基準（最重要）

YouTube台本も「 」内の会話文字数で品質を判断する。話速はUdemyより速め（220〜250字/分）。

| 目的 | 会話文目標 | 推定時間 |
|-----|---------|---------|
| フック・解説 | **750〜1,200字** | 5〜8分 |
| ハンズオン | **1,200〜1,800字** | 8〜12分 |
| まとめ・振り返り | **600〜1,000字** | 4〜7分 |
| Q&A | **750〜1,500字** | 5〜10分 |

## パターン割り込み（必須）

視聴者は2〜3分ごとに離脱を検討する。各パートの切れ目に必ず入れる:
- 「実はここに落とし穴があります」（問題提起）
- 「ここからが本題です」（転換）
- 「この後〇〇を紹介します、最後まで見てください」（予告）

## 品質チェック

| チェック項目 | 基準 |
|-----------|------|
| **会話文字数** | 種類別目標以上（最重要） |
| 1本の主題が1コンセプトか | 2つ以上のテーマを扱っていないか |
| パターン割り込み | 2〜3分ごとに1箇所以上 |
| タイムスタンプ設計 | 概要欄用のタイムスタンプが記載されているか |
| 演出メモ | 各パートに最低1箇所 |
| CTA | 高評価・チャンネル登録・次動画誘導が含まれているか |
| エンドカード指示 | 末尾にあるか |

---

## 完了後の案内
