# /book-toc — 書籍 節別詳細目次

---

## 前提確認
`book/01_structure/chapter_outline.md` が存在しない場合: 「先に `/book-structure` を実行してください」と伝えて終了。

---

## 参考情報の確認（必須）

`references/style-guide.md` はCLAUDE.md読み込み時点でセッションに適用済みのため、目次の記述に反映する。Claude API の各機能を扱う節がある場合、`reference-doc.md`「技術参考情報」のURLをWebFetchで確認し、「カバーするトピック」の記述が実際の機能と齟齬がないようにする。

---

## 生成内容

`book/02_toc/toc.md` を生成・保存する。

```markdown
# 詳細目次: [タイトル]

> 総計: X章 / X節 / 推定Xページ

---

## はじめに（推定Xページ）
- 本書を手に取った読者へのメッセージ
- 対象読者と前提知識
- 本書の全体構成と読み方

## 第1章: [タイトル]（推定Xページ）

### 1-1: [節タイトル]（推定Xページ）
**概要**: [1〜2文]
**カバーするトピック**:
- トピック1
- トピック2
**含める要素**: 説明文 / コード例 / 図解 / コラム

### 1-2: [節タイトル]（推定Xページ）
...

### 章末まとめ（1〜2ページ）

---
（以下繰り返し）

## ページ配分サマリー
| 章 | 節数 | 推定ページ | 累計 |
|---|-----|---------|-----|
| はじめに | — | X | X |
| 第1章 | X | X | X |
| **合計** | **X** | | **Xページ** |

## 品質チェック
- 推定総ページ150ページ以上: ✅/❌
- 各章に「章末まとめ」あり: ✅/❌
```

---

## 完了後の案内
> `/book-chapter [章番号]` で1章ずつ、または `/book-all` で一括執筆できます。
> 例: `/book-chapter 1` → 第1章を執筆 / `/book-chapter 0` → はじめに を執筆
