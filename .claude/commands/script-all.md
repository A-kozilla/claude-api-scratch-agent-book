# /script-all — Udemy 全レクチャー一括生成

---

## 前提確認
`udemy/02_toc/toc.md` が存在しない場合: 「先に `/toc` を実行してください」と伝えて終了。

---

## 処理手順

1. `toc.md` を読み込み、総レクチャー数をカウントして案内する
2. Section 01, Lecture 01 から順に `/script` と同じテンプレート・品質基準で生成・保存する
3. 生成のたびに進捗を表示する:
   ```
   [5/40] ✅ Section 02 - Lecture 01「タイトル」完了（会話文1,720字 / 約9分）
   ```
4. 全完了後に `udemy/03_scripts/progress.md` を生成する:
   ```markdown
   # スクリプト生成進捗
   生成日: YYYY-MM-DD  完了: X/X本

   | # | Section | Lecture | タイトル | 会話文字数 | 推定時間 | 警告 |
   |---|---------|---------|--------|---------|---------|------|
   ```

---

## 完了後の案内

```
✅ 全X本のスクリプト生成完了
総会話文字数: X字 / 推定総時間: X時間X分 / 警告あり: X本

'/slides-all' でスライドを一括生成できます。
'/export udemy' で全スクリプトを1ファイルに結合できます。
```
